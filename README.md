# Tokiko's Order

小説の表紙入稿用に、表紙・背表紙・断ち切り・塗り足しを色分けしたJPEG 画像を生成します。

<img width="1309" height="905" alt="Image" src="https://github.com/user-attachments/assets/af6dd7ef-e821-417d-95be-9a3067a86b37" />

全ての寸法入力はミリメートルです。

C#版とBash＋ImageMagick版を利用できます。

## 必要なもの

- **C#版:** .NET 10 SDK
- **Bash版:** Bash、awk、ImageMagick6または7（`convert`または`magick`コマンド）

C#版は SkiaSharp を使用し、SixLabors のライセンスキーは必要ありません。

LinuxARM64用のSkiaSharpネイティブ資産もプロジェクトに含めています。

## 入力仕様

位置はコマンド引数の順序です。寸法は全て mm で指定します。

| 引数 | 内容                         | 条件                                           |
| ---- | ---------------------------- | ---------------------------------------------- |
| 1    | 断ち切りを含まない表紙の高さ | 0より大きい数値                                |
| 2    | 断ち切りを含まない表紙の幅   | 0より大きい数値                                |
| 3    | 背幅                         | 0以上の数値                                    |
| 4    | 断ち切り幅                   | 0以上の数値                                    |
| 5    | 塗り足し幅                   | 0以上の数値                                    |
| 6    | 出力解像度                   | 350 または 600 DPI                             |
| 7    | 出力先パス                   | 省略可能。省略時は `./tokikosOrder_output.jpg` |

## 使い方

引数は両方の版で共通です。

```text
<表紙高さmm> <表紙幅mm> <背幅mm> <断ち切りmm> <塗り足しmm> <350|600> [出力.jpg]
```

出力先以外の引数は必須です。

表紙の高さと幅は0より大きい数値、背幅・断ち切り・塗り足しは0以上の数値を指定してください。

解像度は350または600 DPIです。

塗り足し幅の2倍は、表紙の高さと幅のそれぞれより小さくしてください。

### C#版

```bash
dotnet build src/TokikosOrder/TokikosOrder.csproj
dotnet run --project src/TokikosOrder -- 210 148 12 3 3 350 ./cover.jpg
```

#### Linux ARM64 実行ファイルの発行

次のコマンドでLinuxARM64用の実行ファイルと依存ファイルを `publish/linux-arm64/` に発行します。

```bash
dotnet publish src/TokikosOrder/TokikosOrder.csproj -c Release -r linux-arm64 --self-contained false -o publish/linux-arm64
./publish/linux-arm64/TokikosOrder 210 148 12 3 3 350 ./cover.jpg
```

発行先の`TokikosOrder`はLinuxARM64用の実行ファイルです。実行環境には.NET10ランタイムが必要です。

### Bash＋ImageMagick版

```bash
./tokikosOrder.sh 210 148 12 3 3 350 ./cover.jpg
```

ImageMagick6と7の両方に対応します。

実行できない場合は、スクリプトに実行権限を付けてください。

```bash
chmod +x tokikosOrder.sh
```

## 画像仕様

出力形式はJPEG（`.jpg`）です。画像全体の寸法は以下の通りです。

| 方向 | 寸法（mm）                         |
| ---- | ---------------------------------- |
| 高さ | 表紙高さ + 断ち切り幅 × 2          |
| 幅   | 表紙幅 × 2 + 背幅 + 断ち切り幅 × 2 |

各領域の始点とサイズは mm 単位です。始点の縦・横は画像左上を `(0, 0)` とします。

| 領域                |                           始点・縦 |                                    始点・横 | 高さ                      | 幅                | 色  |
| ------------------- | ---------------------------------: | ------------------------------------------: | ------------------------- | ----------------- | --- |
| 左の断ち切り        |                                  0 |                                           0 | 表紙高さ + 断ち切り幅 × 2 | 断ち切り幅        | 赤  |
| 上の断ち切り        |                                  0 |                                  断ち切り幅 | 断ち切り幅                | 表紙幅 × 2 + 背幅 | 赤  |
| 表紙1               |                         断ち切り幅 |                                  断ち切り幅 | 表紙高さ                  | 表紙幅            | 緑  |
| 背表紙              |                         断ち切り幅 |                         断ち切り幅 + 表紙幅 | 表紙高さ                  | 背幅              | 青  |
| 表紙2               |                         断ち切り幅 |                  断ち切り幅 + 表紙幅 + 背幅 | 表紙高さ                  | 表紙幅            | 緑  |
| 右の断ち切り        |                         断ち切り幅 |              断ち切り幅 + 表紙幅 × 2 + 背幅 | 表紙高さ                  | 断ち切り幅        | 赤  |
| 下の断ち切り        |              断ち切り幅 + 表紙高さ |                                  断ち切り幅 | 断ち切り幅                | 表紙幅 × 2 + 背幅 | 赤  |
| 表紙1の塗り足し・左 |            断ち切り幅 + 塗り足し幅 |                                  断ち切り幅 | 表紙高さ - 塗り足し幅 × 2 | 塗り足し幅        | 黃  |
| 表紙1の塗り足し・上 |                         断ち切り幅 |                                  断ち切り幅 | 塗り足し幅                | 表紙幅            | 黃  |
| 表紙1の塗り足し・右 |            断ち切り幅 + 塗り足し幅 |            断ち切り幅 + 表紙幅 - 塗り足し幅 | 表紙高さ - 塗り足し幅 × 2 | 塗り足し幅        | 黃  |
| 表紙1の塗り足し・下 | 断ち切り幅 + 表紙高さ - 塗り足し幅 |                                  断ち切り幅 | 塗り足し幅                | 表紙幅            | 黃  |
| 背表紙の塗り足し・上 |                         断ち切り幅 |                         断ち切り幅 + 表紙幅 | 塗り足し幅                | 背幅              | 橙  |
| 背表紙の塗り足し・下 | 断ち切り幅 + 表紙高さ - 塗り足し幅 |                         断ち切り幅 + 表紙幅 | 塗り足し幅                | 背幅              | 橙  |
| 表紙2の塗り足し・左 |            断ち切り幅 + 塗り足し幅 |                  断ち切り幅 + 表紙幅 + 背幅 | 表紙高さ - 塗り足し幅 × 2 | 塗り足し幅        | 黃  |
| 表紙2の塗り足し・上 |                         断ち切り幅 |                  断ち切り幅 + 表紙幅 + 背幅 | 塗り足し幅                | 表紙幅            | 黃  |
| 表紙2の塗り足し・右 |            断ち切り幅 + 塗り足し幅 | 断ち切り幅 + 表紙幅 × 2 + 背幅 - 塗り足し幅 | 表紙高さ - 塗り足し幅 × 2 | 塗り足し幅        | 黃  |
| 表紙2の塗り足し・下 | 断ち切り幅 + 表紙高さ - 塗り足し幅 |                  断ち切り幅 + 表紙幅 + 背幅 | 塗り足し幅                | 表紙幅            | 黃  |

背表紙の塗り足しは上下のみです。背表紙は狭くなる場合があるため、左右には塗り足しを設けません。
